## Code
Every program and code fragment the source shows, copied character for
character, each in its own fenced block that names its language (```c,
```cpp, or the language the source uses). Keep every line break, every
indentation, every comment and every string exactly as the source has them.
Do not correct, complete, modernise, shorten or reformat a listing, even
where it looks wrong, and never write code the source does not contain. A
listing cut by a page break reaches you as two blocks with a page number or a
footer line between them: join them into one block, without that line. Under
each block, one line saying what the code shows. Where the source shows what
a program prints, put that in its own block marked ```text right after the
program. A name or an expression the text quotes inside a sentence belongs
in the explanation, between backticks, not here. Write "None in this
section." if the source shows no code.
